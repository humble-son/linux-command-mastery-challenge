# Day 08: Privilege Escalation & Identity

## Commands of the day

**1. sudo**

This command is used to allow a user run a command with another user's priviledge.

**2. sudo -i**

This command is used to start an iterative login shell as root.

**3. sudo -u**

This command is used to run a command as a specific user other than the root.

**4. sudo !!**

This command is used to run a previous command with sudo priviledge.

**5. sudo -l**

This command is used to list the commands you are allowed to run with sudo.

**6. visudo**

This command is the safe way to edit the sudoers file.

**7. su**

This command is used switch user.

**8. su -**

This command is used to switch to a new user and also loads their login environment.

**9. whoami**

This command simply prints the username you're currently running as.

**10 id**

This command prints detailed identity information.
