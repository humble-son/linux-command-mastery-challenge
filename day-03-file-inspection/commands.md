# Day 03: Reading and Inspecting Files

## Commands of the day

**1. cat**

This command is used to print the entire content of a file to the terminal.

**2. less**

This command allows you to read the content of a file in a scrollable viewer.

**3. head**

This command shows the first 10 lines of a file.

**4. head -n**

This command allows you to specify the number of lines you want to show from the top.

**5. tail**

This command shows the last 10 lines of a file.

**6. tail -f**

This command is used to stream new content of a file as they are appended to the file.

**7. wc**

This command is used to count words, lines and bytes in a file.

**8. wc -l**

This command is used to count only the number of lines.

**9. file**

This command is used to inspect the type of a file. This is becuase a file can be saved with the wrong extension but this command will tell the truth of its content.

**10. stat**

This command is used to show the full details about a file.
