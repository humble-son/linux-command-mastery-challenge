# Day 04: Searching the Filesystems

## Commands of the day

**1. find -name**

This command is used to find a file in the terminal using the name `-name` option.

**2. find -type**

This command is used to find a file in the terminal using the type `-type` option.

**3. find -size**

This command is used to find a file in the terminal using the size `-size` option.

**4. find -mtime**

This command is used to find a file base on when it was last modified.

**5. find -perm**

This command is used to find a file in the terminal base on their permission settings.

**6. locate**

This command is used to search for files by their name instantly. It is very fast than find because it searches a pre-built database.

**7. updatedb**

This command is used to update the database where `locate` fetches its result from.

**8. du**

This command is used to show how much disk space files and directories are consuming.

**9. du -h**

This command is used to show the disk space taken by the directory alone without the subdirectories in human readble format.

**10. df -h**

This command is used to show how much is used and available on a mounted filesystem.
