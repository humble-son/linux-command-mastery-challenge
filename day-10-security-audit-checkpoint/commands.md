# Day 10: Security Checkpoint & Audit

## Commands of the day

**1. find / -perm /4000**

This command is used to search the filesystem for the files matching the criteria.

**2. last**

This command shows the history of user logins, logouts etc.

**3. lastlog**

This command reports the most recent login time for every user account.

**4. w**

This command shows who is currently logged into the system.

**5. who**

This command is used to see a simple list of logged-in users.

**6. groups**

This command displays which groups a user belongs to.

**7. passwd**

This command is used to manage account passwords.

**8. change -l**

This command is used to manage password aging policy.

**9. lastb**

This command lists the failed login attempts.

**10 history | grep sudo**

This command shows your shell's command history for the current user session.
