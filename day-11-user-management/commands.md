# Day 11: Creating & Managing Users

## Commands of the day

**1. useradd**

This command is used to create a new user account on the system.

**2. useradd -m**

This command creates a new user and sets up their home directory.

**3. useradd -m -s**

This command creates a new user with a home directory and login shell

**4. adduser**

This command is a higher level and more interactive wrapper around useradd.

**5. passwd**

This command is used to sets or changes a user's login password.

**6. usermod -aG**

This command displays which groups a user belongs to.

**7. usermod -s**

This command is used to change the shell of a user.

**8. usemod -l**

This command is used to rename a users login name.

**9. userdel**

This command deletes a user account.

**10 userdel -r**

This command deletes a user account and their files.
