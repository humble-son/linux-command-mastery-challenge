# Day 02: Creatinng, Copying, Moving and Deleting

## Commands of the day

**1. mkdir**

This command is used to create a new empty directory.

**2. mkdir -p**

This command allows you to create nested folders in just a single command. In a situation where the parent does not exist yet, it creates it automatically.

**3. touch**

This command creates a new file.

**4. cp**

This command copies a file from one location to another. It does not mutate the original file.

**5. cp -r**

This command is used to copy an entire directory with its content. This is possible because of the introduction of the `-r`

**6. mv**

This command is used to move a file or directory from one place to another.

**7. rm**

This command is used to delete a file.

**8. rm -r**

This command is used to delete a directory.

**9. rm -rf**

This is very dangerous as it has the ability to delete a directory and all its content without any confirmation prompt and `-f` wwill also suppress most warnings.

**10. cd rmdir**

This command is used to delete an empty directory.
