# Day 05: Paths, Links & Tree Structures

## Commands of the day

**1. tree**

This command is used to display the contents of a directory in a tree structure including the subdirectories.

**2. tree -L**

This command is used to limit the number of level deeps tree goes.

**3. ln**

This command is used to create an hard link.

**4. ln -s**

This command is used to create a symbolic link.

**5. readlink**

This command is used to check what file a symbolic link points to.

**6. realpath**

This command is used to resolve a given path to its full absolute path from the root.

**7. basename**

This command is used to get the file name from an absolute path.

**8. dirname**

This command is used to show the directory a file lives in.

**9. pushd/popd**

This command allows you to jump from one directory to another while remembering where you're coming from.

**10. ls -lt**

This command is used to list files in long format and sort them by modification time.
