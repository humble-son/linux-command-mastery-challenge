# Day 09: Integrity, Encryption & Firewalling

## Commands of the day

**1. md5sum**

This command is used to calculate MD5 hash of a file.

**2. sha256sum**

This command works just like md5sum but it's more cryptographically secure.

**3. gpg --gen-key**

This command is used to create a new GPG (GNU Privacy guard) key pair.

**4. gpg --encrypt**

This command is used to encrypts a file using a public key.

**5. gpg -- decrypt**

This command is used to reverse an encryption.

**6. chattr +i**

This command changes special filesystem attributes on a file.

**7. lsattr**

This command is used to lists the special filesystem attributes of files.

**8. ufw enable**

`ufw` means `uncomplicated firewall`: it is a user friendly frontend for managing firewall rules. `ufw enable is used to turn the firewall on`

**9. ufw allow**

This command adds a rule permitting traffic through a specific port.

**10 ufw status**

This command shows whether the firewall is active and lists all currently configured rules.
