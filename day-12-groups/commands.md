# Day 12: Groups & Access Circles

## Commands of the day

**1. groupadd**

This command creates new group on the system.

**2. groupdel**

This command deletes existing group.

**3. gpasswd -a**

This command adds a user to a group.

**4. gpasswd -d**

This command removes a user from a group.

**5. getent group**

This command is used to look up group information.

**6. getent passwd**

This command is used to look up user account information.

**7. groups**

This command is used to show the groups a user belong to.

**8. id -Gn**

This command outputs the name of groups a user belong to.

**9. newgrp**

This command switches your current shell session's active primary group to a group you are a member of.

**10 cat /etc/group**

This command directly displays the raw contents of the system file that stores all local group definitions.
